# Reservoir ML Workbench

**Python 数据处理与机器学习工作流 · 原项目公开代码选集**

本仓库从既有储层参数预测项目中整理出可独立阅读、验证的通用代码：分层数据重采样、样本质量校验、标签来源管理，以及基于整井留出的回归模型比较。它展示数据工程和模型评估方法，不包含现场数据、合作方资料、已训练权重、真实预测结果或原仓库历史。

## 能看到什么

| 模块 | 解决的问题 | 主要实现 |
| --- | --- | --- |
| `resampling.py` | 多源数据深度不一致、缺口插值不受控 | 分层区间采样、最近测井点匹配、最大深度偏差和插值跨度约束；记录源深度与插值标记 |
| `sample_library.py` | 样本重复、标签来源混淆、审核状态混用 | 复合唯一键、合并关系校验、目标级训练资格；区分 measured / formula / unknown；REVIEW 样本仅可预测 |
| `model_compare.py` | 不同模型用不同样本比较、跨井泄漏 | 固定样本队列、整井留出（LOWO）、折内填补与标准化；比较线性回归、梯度提升树和有人工审核类别的模型 |
| `identifiers.py` | 标识格式不一致 | 通用文本标准化；已移除原项目特定井号别名 |

模型比较记录 MAE、RMSE、R² 及有效井数；渗透率在对数空间拟合，反变换后计算原单位误差。原始预测、物理边界裁剪后预测、越界标记分别保留，不用裁剪后的数值替代原始误差。

## 快速验证

验证环境：Python 3.11，依赖版本见 `requirements.txt`。

```bash
python -m venv .venv
# 激活本机虚拟环境后执行
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m examples.synthetic_demo
```

示例和测试中的样本全部由代码构造，井标识为虚构值。示例输出带有 `SYNTHETIC` 标识，只验证程序流程，不能用于推断真实井预测精度。示例不写入数据文件或模型权重。

## 输入约定

- 深度为 MD（m）；孔隙度与含油饱和度使用百分数，渗透率使用 mD。
- 只有明确冻结的区间进入重采样；区间为左闭右开，禁止跨层和跨越过大岩心缺口插值。
- `build_standard_sample_library` 要求调用方显式给出训练井名单，可按目标设置排除名单。
- `measured` 表示标签端点的来源；仍需检查单独的 `*_interpolated` 字段。由测量端点插值得到的标签不等于该深度存在直接实测值。
- 建模前须核实目标级 `*_train_eligible`、来源与插值标记。整井留出不能自动证明每条评价标签都是真实测量值；正式评估仍应限定直接实测标签。
- 模型输入缺少训练资格时默认不纳入；不能把字符串 `"False"` 当成布尔 `True`。
- `PHYSICAL_RANGES` 为从原实现保留的示例配置，不能当作通用于所有储层的科学阈值。
